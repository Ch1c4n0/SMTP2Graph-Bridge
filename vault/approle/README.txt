VAULT APPROLE
=============

EN: This folder receives two files created by scripts\2-configurar-vault.ps1:
      role_id    -> the bridge's "username" in Vault
      secret_id  -> the bridge's "password" in Vault
    They only allow READ access to secret/smtp2graph/entra.
    Do not share them. To replace them, run the script again (option 3).

PT: Esta pasta recebe dois arquivos criados pelo scripts\2-configurar-vault.ps1:
      role_id    -> o "usuário" da ponte no Vault
      secret_id  -> a "senha" da ponte no Vault
    Eles só dão permissão de LEITURA em secret/smtp2graph/entra.
    Não compartilhe. Para trocar, rode o script de novo (opção 3).
